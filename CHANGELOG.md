# Changelog

## 0.9.0 — первая публичная версия

**Туннели**
- Раздельный режим по умолчанию: каждый туннель — свой процесс, порт и systemd user unit
  (автозагрузка через linger, рестарт с нарастающей паузой, зависимости, journald).
- Типы: ssh/autossh, hysteria2, wireproxy, wg-obfuscator, sing-box — `outbound`/`endpoint`
  в YAML, объект из JSON-файла или полный конфиг sing-box.
- Обёртка wg-obfuscator для WireGuard (wireproxy и sing-box), в т.ч. с `WGConfig =`.
- WireGuard: `pre_shared_key`, поля в стиле wg-quick переводятся автоматически.
- HTTP-прокси рядом с SOCKS (`http_port`): силами клиента или через мост HTTP→SOCKS.
- Цепочки `via`: ssh через ProxyCommand, sing-box через detour, подстановки `{via…}`.
- Порты — в одном месте: без `port` в proxies.yaml берутся из файла клиента.
- Комбинатор sing-box (опция): единый вход, ручной выбор, urltest-группы со своими портами.

**Панель**
- Проверка перед запуском: программа установлена, файлы на месте, порт не занят
  (с учётом TIME_WAIT и собственных процессов).
- «Старт» у неприменённого туннеля сам применяет конфиг; плашка «сохранён, но не применён».
- Редактор конфига: статус в окне, переход к строке с ошибкой, «Сохранить всё равно».
- Health-check (задержка, exit IP, HTTP-вход), события, уведомления notify-send,
  «падает в цикле» — один раз и с причиной из журнала.
- Компоненты: проверка обновлений и установка sing-box, hysteria, wireproxy,
  wg-obfuscator в `~/main/bin` с sha256, пробным запуском и откатом.

**pp-run и ярлыки**
- `pp-run <туннель> <программа>`: браузеры — отдельный профиль на туннель, Telegram —
  `tg://socks`, Electron — `--proxy-server`, остальные — переменные окружения,
  `-f` — proxychains4.
- `apps:` → ярлыки в меню приложений с иконкой исходной программы.
